仓库基线与迁移边界
  • 仓库：rust-esp32；主项目：tarot-esp32。
  • 已验证基线：ESP32-C3、ESP-IDF 5.3.1、Rust/C++ 混合、I2S TX 播放、Wi-Fi AP/HTTP。
  • 目标：ESP32-S3、INMP441 I2S RX、Wi-Fi STA/UDP；候选 I2S GPIO4/5/6、按键 GPIO7/8/9、UART0 GPIO43/44。
  • 不做：EDA/PCB、接收端固件、音频输出、裸芯片电路、生产凭据。
