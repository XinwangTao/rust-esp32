tarot-esp32 · Wi-Fi 拉取式 OTA（workflow）

状态：已实现并实机验收（2026-11-02：OTA 0→100% + 坏镜像自动回滚） ｜ 简报 docs/product/esp32s3-ota_brief.md ｜ 旁路 esp32s3-ota_workflow.json
① PC：idf.py build 产出 tarot-esp32.bin，python -m http.server 8000 提供下载
② BLE 触发：App/PC 写控制帧 OTA → 板端回 OTA start
③ Wi-Fi STA：BLE 模式按需启动 Wi-Fi（复用 audio.env 的 SSID/PASSWORD）；连不上 → E1
④ HTTP 下载：esp_http_client 拉 OTA_URL，esp_ota_write 流式写入空闲 OTA 分区
⑤ 校验 + 切换：esp_ota_end 校验 → esp_ota_set_boot_partition → 回 OTA ok → 重启
⑥ 新固件自检：BLE 广播成功 + 麦克风首帧 + PSRAM → esp_ota_mark_app_valid_cancel_rollback()

E1 · 下载/校验失败（来自 ③④⑤）

不切换分区，回 OTA fail:<wifi|http|image>，旧固件继续运行

E2 · 新固件自检失败/崩溃（来自 ⑥）

未标记 valid → bootloader 下次启动自动回滚到旧分区

一次性前置（不在 OTA 流程内）

分区表改双 OTA + 开 rollback 后，需 USB 烧写一次；之后才能 OTA
节点数 6（≤8）；BLE 服务 UUID/音频帧协议不变，App 无需改动。
